«От документа к готовому материалу»: вместо высокого списка один компактный ряд из пяти шагов.

## Не сделано

Тестовый пакет с примерами переводов для скачивания ТЗ предлагает «рассмотреть». Готовых примеров, которые можно публиковать, нет; придумывать их нельзя. Нужны реальные образцы от клиента (с согласием на публикацию), тогда блок со скачиванием добавляется за час.
